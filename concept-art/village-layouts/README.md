# Village Layout Concepts

Top-down concept sketches for all 13 regional boss villages. Each image follows the implemented 16-house layout in `mapgen-village.js`: four diagonal inner-ring houses, twelve outer houses, four cardinal roads, and a central marble fountain plaza. Umbral Sanctum uses the final-region two-gate variation.

The images were generated as visual interpretations of the biome palettes and decoration rules; they are concept art, not exact tile-by-tile renders.
