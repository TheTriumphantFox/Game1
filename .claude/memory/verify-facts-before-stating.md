Before stating a fact, verify it (read the file, run the command, search the source). If it can't be confirmed, prefix the claim with "i think..." rather than asserting it.

**Why:** The user was given unverified assertions and wants confidence level made explicit so they know what to trust without re-checking everything themselves.

**How to apply:** Check the actual source before claiming how code, config, or a tool behaves — don't answer from memory or inference. When verification isn't possible (no access, ambiguous evidence, outside knowledge cutoff), say "i think..." and name what would confirm it.
