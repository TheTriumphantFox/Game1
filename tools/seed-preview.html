Seed Preview

Ready.

Determinism check: generate seed N, note the map, then generate the same seed again. In a properly seeded generator these would be pixel-identical. In this repo today they won't be — every mapgen-*.js file drives its randomness through bare Math.random()/rnd(), and the seed parameter these builders accept is never actually used for randomness (see tools/lint-conventions.py's Math.random() warnings for the full list). This preview surfaces that gap accurately; it doesn't introduce it, and fixing it means threading a seeded RNG through the generation files themselves, not a tools/ change.
